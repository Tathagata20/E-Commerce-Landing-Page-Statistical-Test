# E-Commerce-Landing-Page-Statistical-Test

## Situation
Maven Fuzzy Factory, an online retailer that sells children's toys, needs a marketing analyst.

## Assignment
The website manager noticed that the homepage bounce rate is higher than usual(60%) and decided to test a new landing page. The analyst needs to analyze the results of the new landing page to see if it returns statistical significance.

## Objectives
- Filtering the website traffic
- Calculating the bounce rate
- Verifying significance

## Dataset
https://mavenanalytics.io/data-playground/toy-store-e-commerce-database
